# Oca · Bons hábitos, boas companhias (figma-ana)

Protótipo interativo implementado a partir do design no Figma (**Oca**), contendo todas as 7 telas do fluxo mobile (`402×900`):

- **00 · Criar perfil**
- **01 · Escolha de hábitos**
- **02 · Hoje**
- **03 · Meu progresso**
- **04 · Comunidades**
- **05 · Comunidade de leitura**
- **06 · Meu perfil**
